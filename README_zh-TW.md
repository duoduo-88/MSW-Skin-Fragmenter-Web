# MSW 造型防盜拆解工具 Web

[English](README.md)

MSW Skin Fragmenter Web 是供美術工作流程使用的瀏覽器 PNG 拆解工具。它會將 PNG 的可見區域分配到多張透明碎片，可透過遮罩限制處理範圍，也能加入干擾像素，提高直接拼合與還原的難度。

目前版本：**v1.0.2**

> 圖片拆解屬於混淆輔助措施，不是加密，無法保證圖片絕對不能被還原。

## 主要功能

- 保留 PNG 透明度，將圖片區塊分配至 1～10 張碎片。
- 支援與主圖尺寸相同的選用 PNG 遮罩。
- 可調整基礎方塊尺寸及尺寸隨機倍率。
- 可將原圖像素作為干擾內容加入第 2 張之後的碎片。
- 可在預覽區查看合成結果或個別碎片。
- 支援重新命名及單獨下載 PNG 碎片。
- 可將所有碎片打包成一個 ZIP 檔案。
- 圖片資料在瀏覽器內處理；程式本身不會將圖片上傳至伺服器。

## 使用需求

- 支援 JavaScript、Canvas 與 `OffscreenCanvas` 的現代桌面瀏覽器。
- 除非瀏覽器已快取 JSZip，開啟頁面時需有網路連線。ZIP 匯出會從 jsDelivr 載入 JSZip 3.10.0。
- 建議使用含透明區域的 PNG 主圖。
- 使用遮罩時，遮罩應為與主圖像素尺寸相同的 PNG。

## 本機執行

1. 下載或 clone 本 repository。
2. 使用支援的瀏覽器開啟 `index.html`。
3. 保持網路可用，讓 JSZip 依賴能正常載入。

不需要建置或安裝套件。

## 使用方式

1. 選擇 PNG 主圖。
2. 視需要選擇同尺寸 PNG 遮罩。遮罩中非透明區域會參與拆解，完全透明區域會從結果移除。
3. 設定拆分張數、基礎方塊尺寸及尺寸隨機倍率。
4. 需要增加混淆時保留干擾像素功能；此功能至少需要兩張碎片。
5. 點擊「執行拆解」。
6. 檢查合成預覽及各張碎片。
7. 可重新命名、單獨下載，或將全部碎片匯出為 `fragments.zip`。

介面建議使用 2750 × 3500 的主圖，以符合相關 PSD 工作流程；其他尺寸仍可處理。

## 隱私與網路行為

主圖與遮罩透過瀏覽器檔案 API 讀取並在本機處理，頁面沒有圖片上傳請求。不過頁面會從 `cdn.jsdelivr.net` 載入 JSZip，因此開啟時可能向該 CDN 發出網路請求。

## 限制

- 輸入與輸出格式以 PNG 為主。
- 大尺寸圖片、很小的區塊或很高的隨機倍率可能大量占用記憶體與處理器資源。
- 程式不會強制拒絕尺寸不同的遮罩，使用後可能造成不完整或非預期的裁切。
- 碎片分配使用隨機方式，但不具密碼學安全性。
- 本工具不會建立或修改最終 PSD；匯出的碎片仍需自行放入目標工作流程。
