# MSW 造型防盜拆解工具 Web

[English](README.md)

MSW Skin Fragmenter Web 是一款輕量、在瀏覽器中執行的 PNG 圖像拆解工具，適用於美術作品的輔助保護流程。

目前版本：**v1.1.1**

> 圖片拆解屬於混淆輔助措施，不是加密，無法保證圖片絕對不能被還原。

## 主要功能

- 在本機瀏覽器處理 PNG 並保留透明度
- 支援選用的同尺寸 PNG 遮罩
- 可調整碎片張數、方塊尺寸與尺寸隨機度
- 可選用原圖像素干擾
- 支援合成預覽與單張碎片預覽
- 提供深灰、50% 灰與棋盤格預覽背景
- 支援繁體中文與英文介面
- 支援單張 PNG 與 ZIP 匯出

## 隱私

主圖與遮罩皆在瀏覽器內處理，本專案不會上傳圖片。ZIP 匯出功能會從 jsDelivr 載入 JSZip，因此開啟頁面時可能會連線至該 CDN。

## 相容性

建議使用支援 JavaScript 與 Canvas 的現代桌面瀏覽器。大型圖片或高負載設定可能需要較多記憶體與處理時間。
